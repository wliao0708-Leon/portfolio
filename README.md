# Leon Liao — Portfolio

A standalone static portfolio. Open `index.html` in a browser to preview it. Keep `about.html`, `education.html`, `experience.html`, `projects.html`, `contact.html`, `style.css`, `script.js`, and `assets/` alongside it.

## Publish to GitHub Pages

1. Create a GitHub repository for the website and upload the contents of this folder to the repository root (so `index.html` is at the top level).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Once deployment completes, use the URL shown on the Pages settings screen.

Changes committed to the publishing branch update the site. This folder includes both reports. The SAF PDF is marked confidential; confirm permission before uploading or publishing it. If permission has not been confirmed, remove the SAF PDF and its report link from the published copy.
